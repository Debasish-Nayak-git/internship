🟢 LEVEL 1 — Python Fundamentals

🌡️ Task 1 — Temperature Conversion

Problem Statement:

Create a Python program that converts temperatures between Celsius and Fahrenheit. The program prompts the user to enter a temperature value and the unit of measurement and displays the converted temperature.

Concepts Used:

- User input
- Variables
- Arithmetic operations
- Conditional statements
- Functions
- Temperature conversion formulas

Conversion Formulas:

Celsius → Fahrenheit

F = (C × 9/5) + 32


Fahrenheit → Celsius

C = (F - 32) × 5/9

🚀 Installation & Setup
1. Clone the Repository
git clone <YOUR-REPOSITORY-URL>
2. Navigate to the Repository
cd Python-Developer-Internship
3. Create a Virtual Environment
Windows
python -m venv venv
venv\Scripts\activate
Linux/macOS
python3 -m venv venv
source venv/bin/activate
4. Install Dependencies
pip install -r requirements.txt
5. Run a Task
Navigate to the required task directory:
cd Level-1/Task-1-Temperature-Conversion
Run:
python main.py
